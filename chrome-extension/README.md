# Notepad Web Clipper

Chrome MV3 uzantısı. Araç çubuğundaki Notepad ikonuna basıldığında aktif sekmenin başlığını ve URL'sini Notepad'e yeni not olarak ekler.

## Kurulum

1. Chrome'da `chrome://extensions` sayfasını açın.
2. `Developer mode` seçeneğini açın.
3. `Load unpacked` ile bu klasörü seçin: `chrome-extension`.
4. İkona bastığınızda mevcut sayfa Notepad'e kaydedilir.

## Notepad Adresi

Varsayılan adres `https://not.drtr.uk/`.

Yerelde test etmek için uzantının `Options` ekranında adresi örneğin `http://localhost:8000/` olarak değiştirin.
